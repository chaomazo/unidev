# Security policy

## Supported versions

The main branch is the supported development line. The static site does not currently process credentials or private build uploads.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private security advisory flow for this repository, or contact the maintainers privately through the repository owner profile.

Include:

- A clear description of the issue and its impact.
- Reproduction steps or a minimal proof of concept.
- The affected path, commit, or browser behavior.
- Any suggested mitigation, if you have one.

Please give maintainers reasonable time to investigate before public disclosure. Never include access tokens, passwords, private keys, or private build files in an issue, pull request, or reproduction.
